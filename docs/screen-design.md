## 画面遷移図

### メインフロー（商品を見つけて買うまで）

```
トップページ (/)
  │
  ├─→ 商品一覧 (/products)
  │     │
  │     ├─ フィルター（産地・焙煎度・フレーバー）
  │     ├─ キーワード検索
  │     │
  │     └─→ 商品詳細 (/products/[id])
  │           │
  │           ├─ バリエーション選択（200g / 500g / 1kg）
  │           ├─ レビュー閲覧
  │           │
  │           └─→ 「カートに入れる」
  │                 │
  │                 └─→ カート (/cart)
  │                       │
  │                       ├─ 数量変更 / 削除
  │                       ├─ 配送先選択
  │                       │
  │                       └─→ 「購入する」
  │                             │
  │                             └─→ [Stripe 決済ページ]（外部）
  │                                   │
  │                                   └─→ 決済完了 (/checkout/complete)
  │
  └─→ ログイン (/login) ※未ログイン時にカート等にアクセスした場合
        │
        ├─ Google でログイン
        └─ LINE でログイン
              │
              └─→ 元のページにリダイレクト
```

### マイページフロー

```
マイページ (/mypage)
  │
  ├─→ 注文履歴 (/mypage/orders)
  │     │
  │     └─→ 注文詳細 (/mypage/orders/[id])
  │
  ├─→ プロフィール編集 (/mypage/profile)
  │
  └─→ 配送先管理 (/mypage/addresses)
        │
        ├─ 追加
        ├─ 編集
        └─ 削除
```

### 管理者フロー

```
管理ダッシュボード (/admin)
  │
  ├─→ 商品管理 (/admin/products)
  │     │
  │     ├─→ 商品追加 (/admin/products/new)
  │     └─→ 商品編集 (/admin/products/[id]/edit)
  │
  └─→ 注文管理 (/admin/orders)
        │
        └─→ 注文詳細 (/admin/orders/[id])
              │
              └─ ステータス更新（受注→発送準備中→発送済み→完了）
```

## 共通コンポーネント

| コンポーネント | 表示場所 | 内容 |
|--------------|---------|------|
| ヘッダー | 全ページ | ロゴ、ナビ（商品一覧）、カートアイコン（数量バッジ）、ログイン/ユーザーメニュー |
| フッター | 全ページ | サイト情報、リンク |
| カートアイコン | ヘッダー内 | カート内の商品数をバッジで表示 |
| ユーザーメニュー | ヘッダー内（ログイン後） | マイページ、ログアウト、管理画面（adminのみ） |

---

## 認証ガード

| ページ群 | 必要な権限 | 未認証時の挙動 |
|---------|----------|--------------|
| `/`, `/products`, `/products/[id]` | なし（誰でも閲覧可） | — |
| `/login` | なし | ログイン済みなら `/` にリダイレクト |
| `/cart`, `/checkout/*`, `/mypage/*` | ログイン必須 | `/login` にリダイレクト（元URLを保持） |
| `/admin/*` | admin ロール必須 | 403 or `/` にリダイレクト |
